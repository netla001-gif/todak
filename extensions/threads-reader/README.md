# 토닥 개인용 Threads 읽기

로그인된 Chrome에서 직접 연 Threads 검색 결과를 읽고, 토닥과 동일한 알고리즘으로 정렬하는 개인용 확장 프로그램입니다. 별도 검색 업체나 Meta 검색 API를 호출하지 않습니다.

## 만들기

프로젝트 루트에서 `node scripts/build-threads-reader.mjs`를 실행합니다. 설치 폴더는 `work/threads-reader`입니다. 공통 정렬 알고리즘을 원본 `lib/threads.mjs`에서 복사하므로 원본 수정 후 다시 빌드하세요.

## 설치 및 사용

1. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’로 `work/threads-reader` 폴더를 선택합니다.
2. 도구에서 검색어를 입력하고 ‘Threads 검색 화면 열기’를 누릅니다. 필요한 경우 Threads에서 직접 로그인합니다.
3. 검색 결과가 표시되면 Chrome 확장 프로그램 메뉴에서 ‘토닥 · Threads 나들이 읽기’를 누릅니다. 현재 화면에서 읽은 글이 정렬되어 표시됩니다.
4. 더 많은 글이 필요하면 Threads 화면을 내려 로드한 뒤 도구를 다시 열거나 ‘현재 화면 다시 읽기’를 누릅니다.

## 범위

- 도구를 누른 탭에만 임시 접근하는 `activeTab`과 DOM 읽기 실행을 위한 `scripting` 권한을 사용합니다. 사이트 전체 상시 접근·쿠키·저장소 권한은 요청하지 않습니다.
- 코드에서 Threads `/search` 화면인지 검사한 뒤 본문·작성자·작성 시각·원문 링크만 읽습니다. 메시지·프로필 페이지는 읽지 않습니다.
- 확장 화면의 외부 네트워크 연결을 CSP로 차단합니다. 결과를 서버로 전송하거나 저장하지 않습니다. 결과는 팝업을 닫으면 사라집니다.
- 검색 화면 열기 및 원문 링크 클릭은 Threads를 정상적으로 방문하는 동작입니다.
- 로드된 글 최대 50건에서 최대 30건을 표시합니다. 전체 Threads 자동 수집, 지속 백그라운드 검색, 이미지 안의 글자나 댓글 수집은 하지 않습니다.
- Threads 화면 구조가 바뀌거나 본문이 없는 글은 읽지 못할 수 있습니다. 인접 글을 합치는 것보다 해당 글을 건너뛰도록 구현했습니다.

## 검증

`node --test tests/threads-reader.test.mjs`로 탭 범위 제한, 외부 연결 제한, 정렬·텍스트 표시 및 오류 처리를 확인합니다.

2026-09-06 로그인된 실제 Threads 검색 화면에서 DOM 읽기 로직으로 4개 게시물을 추출했습니다. 설치 전 검증은 읽기 함수의 실제 화면 실행과 확장 프로그램 API를 모사한 팝업 테스트이며, 설치된 확장 프로그램의 전체 흐름 검증은 별도로 필요합니다.
